# geeked.gg

Personal portfolio site for Geeked LLC, generated by a small Haxe program and styled with Tailwind.
No Node or npm: the only tools are `haxe`, `make`, `curl`, and the standalone Tailwind CLI binary
that `make` downloads on first use.

## Prerequisites

- Haxe 4.0 or newer (the generator deliberately avoids newer syntax; CI builds with 4.3.7)
- GNU make, curl, shasum
- python3, only for the local dev server

## Commands

| Command          | Action                                                                 |
| :--------------- | :--------------------------------------------------------------------- |
| `make build`     | Full build into `dist/` (HTML, CSS, assets)                            |
| `make html`      | Run the Haxe generator only (wipes and rewrites `dist/`)               |
| `make css`       | Run Tailwind only (`styles/globals.css` → `dist/styles.css`)           |
| `make assets`    | Copy `public/` into `dist/`                                            |
| `make dev`       | Build, then watch CSS and serve `dist/` at `http://localhost:4321`     |
| `make clean`     | Remove `dist/`                                                         |
| `make distclean` | Remove `dist/` and the downloaded Tailwind binary in `tools/`          |

`make dev` does not rebuild HTML when `.hx` files change. Re-run `make html` in another shell, or
install `entr` and run `ls src/*.hx src/pages/*.hx res/*.html | entr make html`.

## Layout

```
build.hxml            haxe arguments: compile src/ and run Main under --interp
src/Main.hx           entry point; writes dist/*.html, sitemap.xml, robots.txt
src/Html.hx           tiny HTML builder (el / text / raw; attributes are escaped, text is escaped)
src/Layout.hx         <html> shell, header, footer
src/Data.hx           site constants, client logos, services
src/Seo.hx            sitemap + robots
src/pages/*.hx        one class per route, each with a static render()
res/privacy-policy.html   static body of /privacy-policy, wrapped by Layout
styles/globals.css    Tailwind entry + CSS variables + @font-face
tailwind.config.js    Tailwind config (CommonJS; scanned content is src/**/*.hx and res/**/*.html)
public/               copied verbatim into dist/ (favicon, logos, fonts)
scripts/htmlnorm.py   normalizes HTML for structural diffs; used when verifying the Astro migration
```

## Adding a page

1. Create `src/pages/NewPage.hx` with `public static function render():Html` that returns
   `Layout.page("Title", body)`.
2. In `src/Main.hx`, create the output directory and call `write("new-page/index.html", pages.NewPage.render())`,
   and add `/new-page/` to the sitemap list.
3. Keep every Tailwind class list as a single string literal passed to `cls("...")` so the Tailwind
   scanner can find it. Never build class names by concatenation.

## Tailwind

The Makefile pins Tailwind `3.4.19` and verifies the downloaded binary against the release's
`sha256sums.txt`. Bump `TW_VERSION` in the Makefile to upgrade. The standalone binary bundles only
first-party plugins, so third-party plugins cannot be used.

## Deployment

`.github/workflows/build.yml` builds `dist/` on every push and uploads it as an artifact. A GitHub
Pages deploy job is included but stays inert until the repository variable `DEPLOY_PAGES` is set to
`true` and `public/CNAME` contains the domain.
